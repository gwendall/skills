# Routine / daily show mode - writing a topical set on the news

> For writing a late-night monologue / news segment or Daily Show-style piece, from **supplied news** (you're given the headlines/context; don't invent the news, don't go fetch it). Here the full engine applies (you have time, you're going for quality), but a routine **isn't a joke, it's an architecture.** This file adds the structure + freshness layer the KB doesn't have.

## The base brick: "straight setup + turn"
Every news joke = **[the real fact, stated deadpan like a news anchor] + [the turn]**. The setup must be delivered *straight*, credible, journalistic, so the turn surprises. If the setup already flags the joke, the turn is dead.
- Ex (supplied headline: "Airline to start charging for the window seat") -> *"An airline is going to charge extra for the window seat. For passengers who like to know exactly what they're about to crash into."* (straight fact + dark turn last.)

## The freshness contract (the most important step)
On a news item, **a hundred accounts have already made the obvious joke.** This is EXACTLY where AI's blandness is worst. For each topic:
1. Write the cliché take everyone has already made. **Ban it.**
2. Go to the third thought. Look for the human, absurd, *precise* detail in the story, not the macro. The funny is in the specific detail of the actual article, not the general theme.
3. Find the angle nobody took: the absurd-but-logical consequence, the secondary character in the story, the underlying hypocrisy.

## Per-item process (for each supplied item)
1. **Extract the handles**: the concrete jokeable detail (a number, a name, a quote, an object).
2. **Ban the cliché**, aim for the third thought (above).
3. **Overgenerate**: 6-10 angles via the 11 filters + the Toplyn loop (link two distant handles). Keep the best 1-2.
4. **Shape it** as "straight setup + turn", pivot on the last word.
5. **Enrich**: add an act-out or a tag if the premise supports it (see below).
6. Run the 3-gate checklist. Cut without mercy.

## The tools specific to a set (above the joke level)
- **Act-out**: *become* a character from the story instead of narrating it. Almost always funnier. Ex: play the CEO discovering the data leak live, don't describe it.
- **Runner**: a gag/phrase that **recurs** through the set, paying off bigger each time it returns. Pick one early, call it back 2-3 times, cash in at the end.
- **Button / closing callback**: end the set by calling back a bit from the opening. It's the strongest exit; the audience now shares the context.
- **Connective tissue**: *"which raises a question..."*, *"and that's where..."* to link beats with no break.
- **Local angle**: always come down from the abstract theme to the concrete human. Not "the economy is bad" but the precise detail that proves it absurdly.

## Set architecture (the order matters)
- **Open strong, close strong.** Put your two best jokes in **first and last** position. The soft belly goes in the middle (people remember it less).
- **Escalation**: on one topic, chain turns that get more and more absurd but stay logical (the "game": if this is true, what else is true?).
- **Rhythm**: alternate fast one-liners (density) and a more developed beat with an act-out (breathing room). Three quick laughs, then a build.
- **Final button**: close on the callback.

## Segment formats (pick per the request)
1. **Headlines / rapid-fire monologue**: a series of short "straight setup + turn" jokes across several headlines. Maximum density, each headline = 1-2 jokes, keep moving. (Weekend Update / Tonight Show monologue form.)
2. **Desk piece / deep-dive**: a single topic dug into, with a thesis, a runner, act-outs, an escalation, a button. (Daily Show / Last Week Tonight form.)
3. **Fake correspondent / character**: adopt a character POV (the ridiculous expert, the absurdly affected local) and hold the voice throughout.

## Ethics (the news = power)
The news puts the powerful onstage: **punching up** is the default and most defensible setting (institutions, leaders, corporations, the absurdity of systems). Avoid the fresh, identifiable victim of a tragedy ("too soon"). For the tragic, high distance (cf. KB Lever 2).

## Output
- By default: a set ready to perform, in clear beats, no stage directions unless the staged format is requested. Open and close on the best jokes.
- Flag the runner and the button if they exist (they structure the read).
- Write in the requested language. Topical humor is highly cultural: adapt the references to the target audience.
