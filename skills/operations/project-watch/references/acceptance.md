# Cold-start acceptance

A skill file passing formatting checks does not certify a running monitoring
service. Test with a fresh agent that receives only this skill, the private profile
reference and an output destination. Preserve the exact input version and evidence.

## Minimum collecting test

1. Resolve the project, source permissions and canonical memory without chat history.
2. Select manual_refresh for an explicit manual run. Keep scheduled_due and
   digest_only tests separate. A not_due-only run proves no provider collection.
3. Resolve the actual source bindings. Record environment exploration and any
   one-off code needed; these indicate work remaining before unattended rollout.
4. Fetch enabled light sources with bounded requests, actual retrieval times and
   precise checked/partial/unavailable/not_due statuses.
5. Preserve pending queries as well as page cursors when work remains.
6. Persist evidence through canonical memory, read back the result, then replay the
   exact saved payload and verify that it creates no duplicate observation or task.
7. Produce a short briefing that distinguishes fresh checks from inherited evidence.
8. Verify no outward action, owner-review change or unused process remains.

## Cases that need separate proof

- A shared inbox message about another project remains unassigned to this project.
- A 401, 403 or 429 is not converted to zero mentions or messages.
- Stable comment counts do not hide a detected edited or replaced comment.
- A newly discovered old article keeps its publication and first-seen dates separate.
- A partial page or unvisited query is resumed without losing later events.
- A later metrics fetch or local report timestamp does not advance discovery.
- Rounded counts and daily-reset visitor identifiers keep their actual semantics.
- Prior exclusions and human edits survive replay.
- A new article/video is actually read to the claimed coverage, including relevant
  child replies or transcript segments.

Do not claim these cases passed because a quiet live run contained no such event.
Use fixtures or a real relevant case and keep the resulting evidence.

## Unattended readiness

The collecting test is distinct from a stable adapter interface, schema validation,
durable checkpoint implementation, scheduler concurrency and verified delivery.
Those need implementation and an unattended run receipt before the service can be
called active. A model following prose once does not enforce those invariants.
